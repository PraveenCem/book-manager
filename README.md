\# Book Manager PoC



A minimal, production-grade proof of concept built to master MongoDB operations using a Python (FastAPI) backend and React frontend.



\## Tech Stack

\- \*\*Database:\*\* MongoDB

\- \*\*Backend:\*\* Python, FastAPI, Pydantic, Motor (Async MongoDB driver)

\- \*\*Frontend:\*\* React (Vite), Tailwind CSS
